# Rights requiring owner confirmation

No license was present in the source snapshot. The maintainer must choose and approve
licenses for code and data, and establish rights to the sentence corpus, noise images,
and rendered font output. Font names alone do not establish redistribution rights.
No font binaries are added by this change. Do not redistribute font binaries without
permission. The release workflow produces a draft for rights review before publication.

A license cannot be truthfully assigned to third-party assets by an automated audit.
