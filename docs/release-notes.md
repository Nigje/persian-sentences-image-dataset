# Persian Sentences Image Dataset v1.0.0

Original font archives from commit 0440c1caf7f07c2d01b5f8fbc4bcee23c7f60225,
with SHA-256 checksums, metadata, reconstructed sentence labels, and an audit.
Download all ZIPs for all fonts, or one ZIP for a selected font.

See the attached audit for exact counts and annotation issues. Noise identities and the
original rendering process are unknown. Splits group identical transcriptions across
all fonts and variants; they do not guarantee independence of similar sentences.
Before publishing, confirm dataset licensing and third-party rights in docs/rights.md.
